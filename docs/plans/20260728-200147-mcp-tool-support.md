## Chapter 2: Detailed Technical Plan

### 1. Design Overview

```
AgentLoop 构造函数（仅存配置，不做 I/O）
  ├─ this.model / this.tools / this.hooks / this.messages = []
  ├─ 存储各 config 选项（systemPrompt, workspace, projectGuide, skills, mcpServers）
  └─ this.initialized = false

AgentLoop.init()（首次 run() 时 lazy 触发，幂等）
  ├─ resolveWorkspace()        -> workspacePrompt
  ├─ resolveProjectGuide()     -> projectGuidePrompt
  ├─ resolveSkills()           -> skillPrompt + push skill tool
  ├─ initMcpServers()
  │    └─ for each (name, config) in mcpServers:
  │         ├─ new McpClient(config)           // spawn 子进程
  │         ├─ client.initialize()              // JSON-RPC 握手
  │         ├─ client.toolsList()               // 拉取工具列表
  │         ├─ for each tool: new McpTool({ serverName: name, ...client })
  │         │   └─ this.tools.push(mcpTool)     // name = mcp__<name>__<tool>
  │         └─ catch: console.warn(...)，跳过该 server
  ├─ 拼接 systemPrompt = [user, workspace, projectGuide, skill].filter(Boolean).join('\n\n')
  ├─ 非空则 push system message
  └─ this.initialized = true

AgentLoop.run(userMessage)
  ├─ if (!this.initialized) await this.init()
  └─ ...（现有循环逻辑不变）

AgentLoop.close()
  └─ for each client in this.mcpClients: client.close()   // kill 子进程
```

核心数据流：模型返回 `tool_calls: [{ function: { name: 'mcp__server__tool', arguments: '...' } }]` -> agent-loop 按 `definition.function.name` 查找 -> 命中 `McpTool` -> `execute()` 调用 `client.toolsCall(originalName, args)` -> 子进程处理 -> 返回 `{ content: [...], isError }` -> 拼接 text content / `isError` 抛异常 -> 结果作为 `role: 'tool'` 消息进入下一轮循环。

关键测试 case：

- **正常流转**：模型调用 `mcp__server__echo` -> `McpTool.execute()` 返回 text content -> 进入 messages -> 下一轮模型输出最终文本
- **异常分支**：MCP server 返回 `isError: true` -> `McpTool.execute()` 抛异常 -> `postToolUseFailure` hook 可修复 -> 未修复则 error.message 作为 tool result 发给模型
- **边界条件**：单个 server spawn 失败 -> `console.warn` 跳过 -> 其他 server 和本地工具正常工作

**`src/mcp/client.ts`** — `McpClient` 类

```ts
export class McpClient {
  constructor(config: McpServerConfig);

  /** JSON-RPC initialize 握手 + 发送 initialized 通知 */
  async initialize(): Promise<void>;

  /** 获取工具列表 */
  async toolsList(): Promise<McpToolInfo[]>;

  /** 调用工具 */
  async toolsCall(name: string, args: Record<string, unknown>): Promise<McpCallResult>;

  /** kill 子进程 */
  close(): void;
}
```

内部实现要点：
- `spawn(config.command, config.args ?? [], { env: { ...process.env, ...config.env }, stdio: ['pipe', 'pipe', 'pipe'] })`
- 自增 ID 关联请求/响应，`pending: Map<number, { resolve, reject }>`
- stdout 按行缓冲（`buffer += data; lines = buffer.split('\n'); buffer = lines.pop()`），每行 `JSON.parse` 为一条 JSON-RPC 消息
- `initialize` 发送后等待 response，然后发 `notifications/initialized`（notification 无 id、无 response）
- 进程 `error` / `exit` 事件 reject 所有 pending 请求

测试 case（`tests/mcp/client.test.ts`，使用 `tests/fixtures/mock-mcp-server.mjs` 作为真实子进程）：

- C1（正常握手）：`initialize()` 完成，无异常
- C2（工具列表）：`toolsList()` 返回工具数组，`name` / `description` / `inputSchema` 正确
- C3（工具调用-正常）：`toolsCall('echo', { text: 'hi' })` 返回 `{ content: [{ type: 'text', text: 'hi' }], isError: false }`
- C4（工具调用-错误）：`toolsCall('fail', {})` 返回 `{ content: [...], isError: true }`
- C5（关闭）：`close()` 后子进程退出
- C6（异常）：command 不存在 -> `initialize()` reject

**`src/mcp/mcp-tool.ts`** — `McpTool` 类

```ts
export class McpTool implements ToolLike {
  constructor(opts: {
    serverName: string;
    toolName: string;
    description: string;
    inputSchema: Record<string, unknown>;
    client: McpClient;
  });

  readonly name: string;  // mcp__<serverName>__<toolName>

  get definition(): ToolDefinition;

  async execute(args: Record<string, unknown>): Promise<string>;
}
```

`execute()` 逻辑：
1. `const result = await this.client.toolsCall(this.toolName, args)`
2. 拼接 text：`const text = result.content.filter(c => c.type === 'text').map(c => c.text).join('')`
3. `if (result.isError) throw new Error(text)`
4. `return text`

`definition` getter：`name` = `mcp__${serverName}__${toolName}`，`description` = 构造传入值，`parameters` = `inputSchema`（fallback `{}`）

测试 case（`tests/mcp/mcp-tool.test.ts`，mock `McpClient`）：

- M1（命名）：`definition.function.name === 'mcp__test__echo'`
- M2（正常调用）：`execute({ text: 'hi' })` -> 调用 `client.toolsCall('echo', { text: 'hi' })` -> 返回 `'hi'`
- M3（多 content 拼接）：`content: [{ type: 'text', text: 'a' }, { type: 'text', text: 'b' }, { type: 'image', data: '...' }]` -> 返回 `'ab'`，非 text 忽略
- M4（isError 抛异常）：`isError: true` -> `execute()` throw，error.message 为 content 拼接文本

`AgentLoop` 类变更：

```ts
export class AgentLoop {
  private model: Model;
  private userSystemPrompt?: string;    // config.systemPrompt
  private tools: ToolLike[];
  private hooks: AgentLoopHooks[];
  private messages: ChatMessage[];
  private workspaceOption?: boolean;
  private projectGuideOption?: boolean | { path?: string };
  private skillsOption?: boolean | { dir?: string };
  private mcpServersConfig?: Record<string, McpServerConfig>;
  private mcpClients: McpClient[] = [];
  private systemPrompt?: string;        // init() 中构建
  private initialized = false;

  constructor(config: AgentLoopConfig) {
    // 仅存配置，不做任何 I/O
    this.model = config.model;
    this.userSystemPrompt = config.systemPrompt;
    this.tools = config.tools ?? [];
    this.hooks = config.hooks ?? [];
    this.workspaceOption = config.workspace;
    this.projectGuideOption = config.projectGuide;
    this.skillsOption = config.skills;
    this.mcpServersConfig = config.mcpServers;
    this.messages = [];
  }

  /** 初始化：构建 system prompt + 连接 MCP server。幂等。 */
  async init(): Promise<void> {
    if (this.initialized) return;
    this.initialized = true;

    const workspacePrompt = this.resolveWorkspace(this.workspaceOption);
    const projectGuidePrompt = this.resolveProjectGuide(this.projectGuideOption);
    const skillPrompt = this.resolveSkills(this.skillsOption);
    await this.initMcpServers();

    this.systemPrompt = [
      this.userSystemPrompt,
      workspacePrompt,
      projectGuidePrompt,
      skillPrompt,
    ].filter(Boolean).join('\n\n');

    if (this.systemPrompt) {
      this.messages.push({ role: 'system', content: this.systemPrompt });
    }
  }

  /** 连接所有 MCP server，注册工具 */
  private async initMcpServers(): Promise<void> {
    if (!this.mcpServersConfig) return;
    for (const [name, config] of Object.entries(this.mcpServersConfig)) {
      try {
        const client = new McpClient(config);
        await client.initialize();
        const tools = await client.toolsList();
        this.mcpClients.push(client);
        for (const tool of tools) {
          this.tools.push(new McpTool({
            serverName: name,
            toolName: tool.name,
            description: tool.description ?? '',
            inputSchema: tool.inputSchema ?? {},
            client,
          }));
        }
      } catch (e) {
        console.warn(
          `[agent-zero] MCP server "${name}" failed to start: ${e instanceof Error ? e.message : e}`,
        );
      }
    }
  }

  /** 清理 MCP 子进程 */
  close(): void {
    for (const client of this.mcpClients) {
      client.close();
    }
  }

  async run(userMessage: string): Promise<string> {
    if (!this.initialized) {
      await this.init();
    }
    // ...现有循环逻辑不变
  }

  // resolveWorkspace / resolveProjectGuide / resolveSkills / syncSystemPrompt
  // 方法签名不变，参数来源从构造函数直接读取改为从实例字段读取
}
```

集成测试 case（`tests/agent-loop/agent-loop-mcp.test.ts`，使用 `createMockModel` + `tests/fixtures/mock-mcp-server.mjs`）：

- A1（工具注册）：`mcpServers` 配 1 个 server -> `run()` 后 `model.invoke` 收到的 `tools` 含 `mcp__<name>__echo`
- A2（端到端调用）：mock model 返回 `mcp__<name>__echo` tool_call -> 执行后 tool message content 为 echo 结果 -> 下一轮模型输出最终文本

### 6. Risks & Mitigations

- **子进程 stdout 按行拆分的边界**：MCP server 可能在一条消息内输出多个 `\n`，或一次 chunk 不完整。缓冲区方案（`buffer += data; split('\n'); 最后一段留 buffer`）确保不丢消息。回归测试：C1–C3 覆盖正常收发。
- **子进程意外退出**：`process.on('exit')` 和 `process.on('error')` 中 reject 所有 pending 请求。MVP 不做重连。后续 `tools/call` 会因 stdin 已关闭而 reject。
- **既有测试回归**：构造函数不再构建 system prompt，但所有既有测试均在 `run()` 后检查 messages，`run()` 首行 `await this.init()` 确保行为一致。Step 9 中全量回归验证。
