**预期行为变化**：用户在 `AgentLoopConfig.mcpServers` 中声明 stdio MCP server 后，`run()` 首次调用时自动初始化连接（spawn 子进程 + JSON-RPC 握手），拉取远端工具列表并以 `mcp__<server>__<tool>` 命名注册到 `this.tools`。MCP 工具与本地工具统一走 `ToolLike` 接口，preToolUse / postToolUse / postToolUseFailure hooks 天然生效。单个 server 启动失败时跳过并 `console.warn`，不阻塞其他工具。`close()` 方法用于清理子进程。

### 2. Clarification Questions

| # | 问题 | 选项 | 结论 | Review Status |
| --- | --- | --- | --- | --- |
| 1 | 传输协议范围 | A. 仅 stdio / B. stdio + SSE / C. stdio + HTTP | **A**：仅 stdio，MVP 聚焦本地子进程场景 | ✅ |
| 2 | 是否使用 MCP SDK | A. 使用 `@modelcontextprotocol/sdk` / B. 裸写 JSON-RPC | **B**：裸写，不引入 SDK 依赖 | ✅ |
| 3 | 配置格式 | A. 数组 `McpServerConfig[]` / B. map `Record<string, ...>` | **B**：map 格式，key 为 server 名称，可直接复用社区配置 | ✅ |
| 4 | 工具命名空间 | A. `serverName__toolName` / B. `mcp__serverName__toolName` | **B**：加 `mcp__` 前缀，与社区惯例一致 | ✅ |
| 5 | 客户端生命周期 | A. `run()` 内 lazy init / B. 显式 `init()` / C. 构造函数异步 | **A + B 结合**：新增 `init()` 方法，`run()` 首次调用时 lazy 触发；system prompt 构建逻辑也移入 `init()`；`close()` 清理子进程 | ✅ |
| 6 | 工具适配器设计 | A. 扩展 `Tool<T>` 支持 JSON Schema / B. 新建 `McpTool` + 公共 `ToolLike` 接口 | **B**：抽 `ToolLike` 接口，`Tool` 和 `McpTool` 各自实现 | ✅ |
| 7a | MCP 结果 content 转换 | A. 拼接所有 text / B. 仅取第一个 / C. JSON 序列化全部 | **A**：拼接所有 `type: "text"` 的 text 字段，非 text 忽略 | ✅ |
| 7b | `isError: true` 处理 | A. 抛异常走 `postToolUseFailure` / B. 返回字符串走 `postToolUse` | **A**：抛异常，hook 未修复时 error.message 作为 tool result 发给模型 | ✅ |
| 8 | server 启动失败 | A. fail fast / B. 跳过并继续 | **B**：跳过该 server，`console.warn` 提示，不阻塞 | ✅ |

### 3. 需求演进与 Review 历史

**原始需求**（用户描述，概括保持原意）：

给 AgentLoop 加上 MCP tool 的能力。MCP resource 和 MCP prompt 这部分先不用处理，只做 MCP tool。

**Review 阶段提出的技术问题**（只记录问题）：

1. MVP 阶段支持哪些 MCP 传输协议（stdio / SSE / streamable-http）？
2. 是否使用官方 `@modelcontextprotocol/sdk`，还是裸写 JSON-RPC 协议？
3. 配置格式用数组还是 map？是否需要兼容社区常见格式（如 Claude Desktop 配置）以便直接复制？
4. MCP 工具的命名空间方案？是否需要 `mcp__` 前缀？
5. MCP 客户端的连接/断开生命周期如何管理？构造函数同步、MCP 握手异步的矛盾如何解决？system prompt 构建逻辑是否一并重构到 `init()`？
6. MCP 工具如何与现有 `Tool<T>` 类适配？是否需要抽公共接口？Zod schema 校验如何处理？
7. MCP `tools/call` 返回的 content 数组如何转成 string？`isError: true` 时走 hook 的哪条路径？错误最终是否可达模型？
8. 单个 MCP server 启动失败时，是阻塞整个 AgentLoop 还是跳过继续？
